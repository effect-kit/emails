# @effect-kit/emails

Effect v4 native email services with interchangeable provider Layers (planned).

This package currently contains only the build scaffold. It does not expose a sending API or provider
adapters yet. The intended requirements are Effect v4 and an explicitly installed SDK for each provider
used by the application.

The package is ESM-only. Builds emit JavaScript, declarations, and maps into `dist/`. Only `dist/`,
this README, and the Apache-2.0 license are included in the package tarball.
